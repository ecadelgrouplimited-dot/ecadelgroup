# Testimonial Drafts — Awaiting Client Sign-Off

**Status: NOT LIVE. Do not copy these into `components/sections/Testimonials.tsx`
until the named client has approved the wording in writing.**

A testimonial on ecadelgroup.com is a public endorsement attributed to a real
person at a real company. Writing one on their behalf — however accurate the
underlying facts — misrepresents them. Everything in this file is a starting
point for a conversation with the client, not copy.

## How to use this file

1. Send the draft to the client as *"here's a suggestion, please edit freely or
   write your own."*
2. Get approval by email and keep it.
3. Move the approved text into the `testimonials` array in
   `components/sections/Testimonials.tsx`.
4. Delete the draft from this file.
